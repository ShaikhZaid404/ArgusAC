## Reporting a Vulnerability

If you discover a security vulnerability, crash exploit, or detection bypass within **ArgusAC**:

1. **Do NOT open a public GitHub issue.** Publicly disclosing vulnerabilities exposes production servers to malicious exploitation.
2. Email the maintainer or report privately via GitHub Security Advisories at:
   `https://github.com/ShaikhZaid404/ArgusAC/security/advisories/new`
3. Include:
   - Specific Minecraft / Paper / Folia build version.
   - Exact client modification or cheat payload used.
   - Network packets or reproduction steps.

Security reports are prioritized, reviewed, and resolved promptly.
